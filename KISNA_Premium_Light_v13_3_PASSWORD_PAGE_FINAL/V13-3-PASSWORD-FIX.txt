KISNA v13.3 — RESTABLECIMIENTO DE CONTRASEÑA

CORRECCIÓN PRINCIPAL
La recuperación de contraseña ya no se abre dentro de /admin/.
Ahora se utiliza una página independiente:
https://kisnalisado.es/recuperar.html

FLUJO
1. Netlify envía un enlace a https://kisnalisado.es/#recovery_token=...
2. La portada guarda el token temporalmente y abre /recuperar.html.
3. La nueva página verifica el token.
4. Aparece un formulario propio para escribir y repetir la contraseña.
5. Al guardar, se puede entrar en /admin/ con el correo y la nueva contraseña.

DESPUÉS DE DESPLEGAR
- Espera a que Netlify indique Published.
- Solicita un NUEVO correo de restablecimiento.
- Usa solamente el enlace del correo más reciente.
- No reutilices enlaces antiguos, porque los tokens son de un solo uso o pueden caducar.

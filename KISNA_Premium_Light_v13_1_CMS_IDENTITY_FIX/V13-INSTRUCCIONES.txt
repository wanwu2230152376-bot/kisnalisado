KISNA v13 CMS

Estructura lista para GitHub + Netlify + Decap CMS.

Después de subir todos los archivos a GitHub:
1. En Netlify: Project configuration > Identity > Enable Identity.
2. Registration preferences: Invite only.
3. Services > Git Gateway > Enable Git Gateway.
4. Identity > Invite users: invita tu propio correo.
5. Abre https://kisnalisado.es/admin/ y crea tu contraseña desde el correo de invitación.
6. En el panel: Resultados antes y después > Galería de resultados.

IMPORTANTE: no borres la carpeta assets ni data.
